# Açaí da Quel

Site responsivo da **Açaí da Quel**, em Itaquera, desenvolvido com HTML, CSS e JavaScript.

## Destaques

- Design responsivo para desktop e mobile
- Animações com GSAP, ScrollTrigger e SplitText
- Marquee contínuo
- Menu mobile animado
- Interações magnéticas nos botões
- Açaí que acompanha o cursor na seção de endereço
- Fotos reais da loja

## Produção

- [Site na Vercel](https://acai-da-quel.vercel.app)
- [Instagram](https://www.instagram.com/acaidaquel__/)

## Tecnologias

HTML5, CSS3, JavaScript e GSAP.
